# Release notes

Per-version release notes for Wilder Screen Keys live here. Each version has its own Markdown file: `v1.0.0.md`, `v1.0.1.md`, and so on.

The actual binary artifacts (installers, portable executables, checksums, signatures) are attached to the corresponding [GitHub Release](https://github.com/wlstudio/wilder-screenkeys/releases), not committed to this directory.

## Format

Each release note file should include:

- Version and release date
- Summary (one or two sentences)
- New features
- Fixes
- Known issues
- Upgrade notes (only when relevant)
- SHA-256 checksums of the installer artifacts

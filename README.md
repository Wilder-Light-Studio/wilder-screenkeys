# Wilder Screen Keys

**Keyboard-driven mouse control for accessibility.** Move the cursor with arrow keys, click with the spacebar. Built for people with arthritis, RSI, or limited hand mobility.

This repository hosts the **public product website**, **release builds**, and **end-user documentation** for Wilder Screen Keys. The source code lives in a separate repository.

- **Website:** https://wlstudio.github.io/wilder-screenkeys/
- **Buy / get a license:** see [pricing](pricing.html)
- **Contact:** teamwilder@wildercode.org

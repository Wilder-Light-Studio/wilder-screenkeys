# Installers

Signed Windows installers are published as assets on the [GitHub Releases](https://github.com/wlstudio/wilder-screenkeys/releases) page rather than committed to this directory (binaries inflate repository size and don't diff usefully).

This directory exists so that the layout is obvious to anyone browsing the repo, and as a workspace for installer build configuration (Inno Setup or WiX scripts) if and when those move into this repo.
